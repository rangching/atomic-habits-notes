# 原子習慣：1% 的科學 × 行動實驗室：學習網頁

純靜態網頁（GitHub Pages）。內容在 `content.js`，影片連結在 `videos.js`（由流水線自動回寫）。

本機預覽：`python3 -m http.server 8195`

內容原始檔在 `_units/`（`_series.js`＋`u01.js`…`u11.js`），改完執行 `python3 _units/build.py` 重建 `content.js`；練習題答案由 `_units/calc_uNN.py` 計算。

本系列為自製讀書筆記，以改寫方式整理 James Clear《原子習慣》與 Companion Works 練習本的概念並對照公開研究，不收錄原書文字與圖片。
